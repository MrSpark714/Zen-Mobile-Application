# Zen Light Minimalist — Android Material Design 3 Design System & Implementation Guide

## 1. Overview & Philosophy
Zen Light translates ZEN's signature dark aesthetic into a clean, distraction-free daylight environment. Rather than utilizing harsh high-chroma neon greens which fail contrast checks on white surfaces, Zen Light utilizes a dual lime system:
- **Interactive Accent / Brand Surface**: `#ECFCCB` (Lime 100 Container) paired with `#4D7C0F` (Lime 700 Deep Olive) for crisp AA/AAA contrast.
- **Floating Action & Key Highlights**: `#65A30D` / `#BEF264` with darkened border definition and `#131313` typography.
- **Card Surfaces**: Pure white `#FFFFFF` cards over crisp light grey `#F8F9FA` canvas with `#E4E4E7` hair-line borders.

## 2. Core Color Token Mapping (Dark → Light)
- `Canvas / Background`: `#121212` / `#131313` ➔ `#F8F9FA` / `#FFFFFF`
- `Surface Container High (Cards)`: `#1C1B1B` / `#202020` ➔ `#FFFFFF` (with `#E4E4E7` border)
- `Surface Container Highest (Modals / Elevated)`: `#2A2A2A` ➔ `#F1F3F5`
- `Text Primary`: `#FFFFFF` / `#F4F4F5` ➔ `#121212`
- `Text Secondary / Muted`: `#A1A1AA` ➔ `#52525B`
- `Accent Active Pill (MD3 Dock)`: `#BEF264` ➔ `#ECFCCB` container with `#1A2E05` active icon & text
- `FAB Button`: `#BEF264` ➔ `#A3E635` / `#BEF264` with `#0F172A` icon
- `Destructive`: `#FF453A` ➔ `#DC2626` text, `#FEE2E2` container

## 3. UI Component Specifications
### Bottom Navigation Bar (MD3)
- Background: `#FFFFFF` with `border-t border-[#E4E4E7]`
- Pill indicator: `w-16 h-8 rounded-full bg-[#ECFCCB]`
- Active icon/text: `#1A2E05` (high legibility)
- Inactive icon/text: `#71717A`

### Timetable & Class Cards
- Background: `#FFFFFF`
- Border: `1px solid #E4E4E7`
- Shadow: `elevation-level-1`
- Type Badges:
  - Theory: `#E0F2FE` (Cyan container), text `#0369A1`
  - Lab: `#F3E8FF` (Purple container), text `#7E22CE`
